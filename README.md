# Smart Pantry Manager

A smart pantry manager is designed to assist users with meal preparation using ingredients that they already have. The recipes embedded use simple ingredients and are quick and easy to make healthy
 meals.

The smart pantry manager uses a strict matching algorithm that only displays embedded recipes with only the ingredients that you already have.

This app allows you to add, update, and delete items from your pantry. This app has a screen that allows you to view all the items in your pantry. There is a screen that shows you a list of recipes that you can make using the ingredients. It shows you what ingredients are required for the recipe and how to prepare the dish. There is a settings option that allows you to get notifications when an ingredient is expiring so that you can use it. This allows you to use all the ingredients that you have resourcefully. There is a navigation bar that allows you to view recipes that you can make, ingredients that you have and a settings panel.


The the tech stack used for the project is as follows:
Languages: Java and XML for the logic and user interface 
IDE: Android Studio
Database: SQLite
Version control: Github

There are 3 tables in the database:
Pantry items - which stores the ingredients that the user owns
Recipes - which store the recipe name and steps
Recipe ingredients - each ingredient that a recipe requires using a recipe ID


Setup instructions:
Clone the repository 
Open Android Studio and open the folder where the repository was cloned
Setup a device in android studio for the app to run
Run the app
